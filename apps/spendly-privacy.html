Privacy Policy / Integritetspolicy

Effective date / Ikraftträdande: 2026-03-03 • Developer / Utvecklare: R&M Group AB • Contact / Kontakt: info@rmdesigns.se

English

This Privacy Policy applies to Spendly, developed by R&M Group AB. Spendly is provided "AS IS".

Information We Collect

  • Data you enter in the app: budget information such as incomes, expenses, categories, and notes.
  • Device/app data: limited technical and usage data (for example app interactions, device/app information, and crash/diagnostic events) via analytics tools.
  • Anonymous user identifier: Spendly uses anonymous Firebase Authentication to create a technical user ID for app functionality.

How Data Is Used

  • To provide core budgeting features.
  • To enable optional sharing/collaboration features.
  • To measure app usage and improve stability and functionality.

Where Data Is Stored

  • Local on your device: your personal budget data is stored locally.
  • Cloud (when sharing/collaboration is used): shared sheets and related metadata are stored in Firebase Cloud Firestore so invited users can access shared content.
  • Analytics data: event/usage data is processed through Firebase Analytics.

Third-Party Services

Spendly may use:

  • Google Play Services
  • Firebase Analytics
  • Firebase Authentication (Anonymous)
  • Cloud Firestore

Advertising

Spendly does not use AdMob at this time.

Children

Spendly is not directed to children under 13, and we do not knowingly collect personal information from children.

Security

We use reasonable technical and organizational measures to protect data, but no method is 100% secure.

Data Deletion

  • Local data can be removed by uninstalling the app.
  • For shared cloud data, contact us at info@rmdesigns.se to request deletion where applicable.

Changes to This Policy

We may update this Privacy Policy. Continued use after updates means you accept the revised policy.

Svenska

Denna integritetspolicy gäller Spendly, utvecklad av R&M Group AB. Appen tillhandahålls i befintligt skick.

Vilken data vi samlar in

  • Data du matar in i appen: budgetinformation som inkomster, utgifter, kategorier och anteckningar.
  • Enhets-/appdata: begränsad teknisk data och användningsdata (t.ex. apphändelser, enhets-/appinformation och krasch-/diagnostikdata) via analystjänster.
  • Anonymt användar-ID: Spendly använder anonym Firebase Authentication för att skapa ett tekniskt användar-ID för appfunktionalitet.

Hur data används

  • För att tillhandahålla appens budgetfunktioner.
  • För att möjliggöra valfria delnings-/samarbetsfunktioner.
  • För att analysera användning och förbättra stabilitet och funktion.

Var data lagras

  • Lokalt på din enhet: din personliga budgetdata lagras lokalt.
  • Molnet (vid delning/samarbete): delade ark och relaterad metadata lagras i Firebase Cloud Firestore så att inbjudna användare kan komma åt delat innehåll.
  • Analytics-data: händelse- och användningsdata behandlas via Firebase Analytics.

Tredjepartstjänster

Spendly kan använda:

  • Google Play Services
  • Firebase Analytics
  • Firebase Authentication (anonym inloggning)
  • Cloud Firestore

Annonser

Spendly använder inte AdMob för närvarande.

Barn

Spendly riktar sig inte till barn under 13 år och vi samlar inte medvetet in personuppgifter från barn.

Säkerhet

Vi vidtar rimliga tekniska och organisatoriska säkerhetsåtgärder, men inget system är helt säkert.

Radering av data

  • Lokal data kan tas bort genom att avinstallera appen.
  • För delad molndata kan du kontakta oss på info@rmdesigns.se för begäran om radering där det är tillämpligt.

Ändringar

Vi kan uppdatera policyn. Fortsatt användning efter uppdatering innebär att du accepterar den reviderade policyn.
